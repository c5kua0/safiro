# Safiro

Safiro is a Paper 26.2 Minecraft plugin built with Java and Maven.

## Features

- Safiro main system GUI
- Magic item slot management
- Safiro Points economy
- Crafting and upgrade systems
- Passive and active magic item abilities
- Secret Chad and God Wings content
- Persistent player data using Bukkit configuration files
- GitHub Actions build workflow for Maven packaging

## Build

```bash
mvn clean package
```

## Run on Paper 26.2

Place the generated JAR in your Paper server's plugins directory and restart the server.
